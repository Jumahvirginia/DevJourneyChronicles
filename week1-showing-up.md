## Documenting my journey one week at a time.  
_“Chasing consistency, not perfection.”_

### 📍 Why I’m Doing This

I’ve always said I’d “lock in,” take my coding journey seriously, and build a career in tech. Truth is, I’ve had chances before. Opportunities I didn’t fully take. I’ve started, stopped, gotten 
distracted, or just doubted myself.
But this time, I’m choosing to show up differently. I’m taking this opportunity with the Power Learn Project (PLP) as a challenge to myself. I want to stay consistent all the way through and finally build something real. It’s a promise to remain committed, even when it gets tough.
This blog is my way of holding myself accountable. I want to document every step: the progress, the confusion, the small wins. This journey matters to me. And if you’re in a similar place, maybe it’ll remind you to keep going too. ✨

### 🧰 Getting Set Up (Tools + First Impressions)
The first few days were mostly about getting my environment set up. Honestly, I didn’t expect that to be such a big part of learning to code. But it really was. Setting up the tools felt like learning in itself. 😅
We installed everything we’d need for the journey ahead:
-	✅ VS Code
-	✅ Python
-	✅ MySQL
-	✅ Flutter and Dart
-	✅ Git and GitHub
Thankfully, the setup process went smoothly for me. No major errors. I just followed instructions and ticked things off one by one.
The only thing that gave me pause was Git Bash. That black screen with blinking text, the commands, the unfamiliar flow... 👀 It wasn’t hard to install, but actually using it? That’s where the real learning began.

### 💻 My Git Breakthrough
Out of everything we did this week, Git was definitely the part that challenged me the most.
I’ve tried getting into coding before. I’ve taken a few courses here and there, but I never really stuck with any of them. And every time Git came up, I’d shy away. I’d seen the commands and heard people talk about them, but I never really understood what they did. It always felt too technical, so I avoided it.
This time, I didn’t run. I showed up. I opened Git Bash, typed the commands, and followed along, even when I didn’t fully understand what I was doing.
During the first Git class, I was mostly just copying and pasting, trying not to mess up. But in the recap session, something finally clicked. 💡 For the first time, I understood the flow. I saw how Git tracks your changes and how GitHub helps you share your work online.
And honestly? That moment when I ran the commands on my own and they actually worked, I felt like a genius. 🤓 I was finally understanding what used to confuse me. That little win gave me a huge confidence boost.
 ##### 📌 Git Commands I Learned This Week:
-	git init → Start a new Git project
-	git add → Track changes you’ve made
-	git commit -m "message" → Save your progress with a message
-	git branch -M main → Rename the branch to main
-	git remote add origin [URL] → Link your project to GitHub
-	git push -u origin main → Push your code to GitHub
-	git pull → Bring changes from GitHub to your local machine
 
### 🚀 Wrapping Up Week 1
This week was amazing. From installing tools to learning Git, it was both a little challenging and a lot of fun. I’m proud that I showed up and kept going, especially during the moments I wanted to shy away.
The plan is not to pressure myself to be perfect. I just want to stay consistent, no matter how messy or confusing it gets. That’s my goal. That’s the challenge I’ve set for myself.
Week 1 reminded me that progress can be quiet, but it still counts. Week 2, here I come. 🔥
